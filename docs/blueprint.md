# **App Name**: MUBAS Community Hub

## Core Features:

- User Authentication: Secure user login and registration with role-based access control (student, admin).
- Hybrid Search Functionality: Unified search across knowledge base articles and community forum questions with filtering. This feature provides suggested search terms, and the system uses that context as a tool for making a more informed recommendation of article, post, or similar.
- Question Posting: Allow students to post questions with tags and categories.
- Community Forum: Enable users to respond to the community questions by adding additional information in the tool so that the tool can better extract the best answer.
- Admin Knowledge Base Management: Create, edit, and moderate knowledge base articles.
- User Profile Management: Allow users to manage their profile, preferences, and notifications.
- Content Moderation: Enable admins to moderate user-generated content, ensuring relevance and quality.

## Style Guidelines:

- Primary color: MUBAS Blue (#0A3A67) for a modern and trustworthy feel.
- Background color: Off-white (#F8F9FA) to ensure high readability.
- Accent color: Energetic Teal (#008080) for calls-to-action and highlights.
- Headings: 'Inter' (sans-serif) in Bold or Semi-Bold for a clean and modern look.
- Body Text: 'Inter' (sans-serif) in regular weight for maximum readability.
- Custom line-art icons with a consistent stroke weight representing various topics (Academics, Campus Facilities, etc.).
- Subtle fade-in animations as the user scrolls, and smooth transitions on interactive elements.
